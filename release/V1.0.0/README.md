# DPS Meter v1.0.0

A precompiled release of DPS Meter for **Shape of Dreams**.

## Installation

1. Download `DPSMeter-1.0.0.zip`.
2. Extract the ZIP.
3. Copy the extracted `DPSMeter` folder into the game's installation folder under `mods`. Create `mods` if it does not exist.
4. Verify the final paths include:
   - `mods/DPSMeter/DPSMeter.dll`
   - `mods/DPSMeter/about/metadata.json`
   - `mods/DPSMeter/about/description.txt`
5. Launch the game.

Do not copy only the DLL; keep the `about` folder alongside it. Also avoid accidentally nesting the folder twice (for example, `mods/DPSMeter/DPSMeter/DPSMeter.dll`).

## Included features

- Current and total damage tracking, with skill and Essence breakdowns
- Healing and barrier metrics
- Party contribution comparisons
- Recent run history
- Optional display filters for overkill, overheal, and Essence of Mortality damage
- Movable meter, settings, and context-menu controls
